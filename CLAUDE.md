# gopnik-mobile — правила для ИИ-помощников

Концепция и все договорённости: [GAME_DESIGN_DECISIONS.md](GAME_DESIGN_DECISIONS.md). Режим выживания: [SURVIVAL_DESIGN.md](SURVIVAL_DESIGN.md).

## Правила
- Графику не рисуем сами: пишем ТЗ в `art/REQUEST_XX_*.md` и пушим в GitHub; ChatGPT рисует, согласует с пользователем и кладёт готовые файлы в `art/`. Мы подключаем готовое в игру. Исключение — по прямой просьбе пользователя Claude рисует сам (кодом SVG→webp), как заказ 05 иконок.
- Старые сборки (`kazan/`, `preview-v1`…`preview-v5`) не менять; новое — в новой папке `preview-vN`.
- Код игры меняем только по явному разрешению пользователя; дизайн фиксируем в GAME_DESIGN_DECISIONS.md.
- Всё в игре выдуманное, но похожее на Казань 1998: никаких настоящих названий улиц, районов и группировок (в коде, тексте и на картинках).
- Карты и сцены улицы — всегда **две версии одного кадра: лето и зима** (одинаковая композиция). Осень и весна — летняя/зимняя картинка + дождь/слякоть эффектом игры, отдельно не рисуются.
- Перед каждой отправкой изменений игры в GitHub — автотесты: `cd tests && npm install && node run.js` (см. tests/README.md). Пушить только если «Все сценарии прошли». Новые механики — с новым сценарием в tests/cases/.
- Вывески и надписи на картах и сценах разрешены (решение 20.11.2026), кроме настоящих названий улиц, районов, группировок и брендов. На иконках предметов — без текста.
