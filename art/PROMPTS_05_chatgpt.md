# Заказ 05 — готовые промпты для ChatGPT (44 иконки)

Цель — иконки **в том же стиле, что заказ 01** (образец: [reference/style_items_01.webp](reference/style_items_01.webp)): живописный реализм, старые потёртые вещи, свет сверху слева, прозрачный фон.

## Как работать
1. Открыть новый чат ChatGPT, **прикрепить картинку** `art/reference/style_items_01.webp` и отправить **стилевое сообщение** (ниже) — один раз на чат.
2. Дальше отправлять по одной строке «Нарисуй: …» из таблиц. Одна иконка = одна картинка.
3. Если вышло не так — «перерисуй, ближе к образцу: …» (что не так).
4. Скачать PNG и назвать **точно как в колонке «Файл»**, но можно `.png` и любого размера (ChatGPT отдаёт 1024×1024).
5. Положить в папку `art/incoming/05/` (через GitHub: Add file → Upload files). Claude сам уменьшит до 256×256, переведёт в `.webp`, проверит вес и разложит в `art/items/`.

Совет: после 8–10 картинок стиль «уплывает» — начать новый чат и снова отправить стилевое сообщение с образцом.

## Стилевое сообщение (копировать целиком)
```
Ты рисуешь иконки предметов для мобильной игры про бедную постсоветскую жизнь, город 1998 года, зима.
Стиль — строго как на прикреплённом образце: живописная цифровая иллюстрация, почти реализм,
старые потёртые грязноватые вещи, приглушённая тёплая охристая палитра (ржавчина, выцветший красный,
советский зелёный, серый), мягкий свет сверху слева, лёгкая тень под предметом.
Правила для каждой иконки:
- один предмет (или небольшая кучка) по центру, занимает ~80% кадра, вид 3/4 сверху;
- ПРОЗРАЧНЫЙ фон (PNG), квадрат 1024×1024, без рамки, без подложки, без пола;
- никакого текста, букв, цифр, логотипов и брендов (на этикетках — только неразборчивые пятна);
- без людей и рук; без мультяшности, аниме и фотореализма.
Отвечай только картинкой. Сейчас пришлю первый предмет.
```
