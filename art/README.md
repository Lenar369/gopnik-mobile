# Графика для «Гопник: Казань 1998» — правила для художника (ChatGPT)

Эта папка — **заказы на рисовку**. Claude пишет ТЗ, ChatGPT рисует, пользователь согласовывает, готовые файлы кладутся сюда же в GitHub. Claude потом подключает их в игру.

## Порядок работы
1. Открыть файл заказа `REQUEST_XX_*.md` (начинать с наименьшего номера, где есть строки со статусом ⏳).
2. Нарисовать позиции **строго по таблице**: имя файла, размер, описание.
3. Показать пользователю, внести правки.
4. Положить файл в указанную папку (`art/items/`, `art/hud/`, `art/scenes/`, `art/loot/`) **с точно таким именем файла**.
5. В таблице заказа поменять статус ⏳ на ✅ (или ❌ с причиной).
6. Коммит: `art: <что добавлено>` — например `art: иконки еды (8 шт.)`.

Если положить файл в GitHub напрямую нельзя — пользователь загружает его через сайт GitHub: Add file → Upload files в нужную папку.

## Общий стиль (обязательно для всех)
- **Эпоха и место**: Казань (вымышленный город), 1998 год, постсоветская бедность, панельки, рынки, гаражи, зима.
- **Техника**: живописная цифровая иллюстрация (как карты районов в `preview-v5/maps/`), реализм с лёгкой «картинностью», без мультяшности, без аниме, без фотореализма.
- **Палитра**: приглушённая, тёплая, грязновато-охристая; акценты — ржавчина, выцветший красный, советский зелёный. Без неоновых цветов.
- **Свет**: всегда **сверху слева**, мягкий.
- **Без текста и надписей** на картинках (буквы на этикетках — неразборчивые, намёком). Без логотипов реальных брендов.
- **Без** людей с узнаваемыми лицами реальных персон.
- **Город выдуманный**, но похожий на Казань 1998: никаких настоящих названий улиц, районов, заводов и группировок, без копирования конкретных реальных зданий.
- **Карты и уличные сцены — всегда два варианта одного кадра: лето и зима** (детали на тех же местах). Осень и весну не рисуем — игра добавляет дождь сама.

## Технические требования
| Тип | Папка | Размер | Формат | Фон |
|---|---|---|---|---|
| Иконка предмета | `art/items/` | 256×256 px | `.webp` (или `.png`) | **прозрачный** |
| Иконка интерфейса | `art/hud/` | 128×128 px | `.webp` (или `.png`) | **прозрачный** |
| Сцена/экран | `art/scenes/` | 1032×581 px | `.webp` | непрозрачный |
| Место вылазки | `art/loot/` | 1032×581 px | `.webp` | непрозрачный |
| Интерфейс | `art/ui/` | см. заказ 03 | `.webp` | см. заказ 03 |
| Карта | `art/maps/` | см. заказ 04 | `.webp` | непрозрачный |

- Иконка предмета: предмет по центру, занимает ~80% кадра, вид 3/4 сверху, тонкая тёмная обводка/тень снизу, чтобы читался на тёмном фоне интерфейса.
- Размер файла: иконка ≤ 60 КБ, сцена ≤ 250 КБ.
- Имена файлов — только латиница, маленькие буквы, подчёркивания, **точно как в таблице**.
