# Музыка игры

Сюда класть треки в формате **mp3** (можно взять как есть из генератора; лучше до 3 МБ, 128–192 кбит/с).
Имена — латиницей без пробелов, например `02_dvor_vecherom.mp3`.

Чтобы трек заиграл в игре, его надо добавить в список `preview-v6/data/music.js`:
```js
 {title:'Название для меню',src:'../art/music/02_dvor_vecherom.mp3'},
```
Треки играют по очереди в случайном порядке, один и тот же два раза подряд не повторяется. В меню игры есть «⏭ Следующая мелодия».
