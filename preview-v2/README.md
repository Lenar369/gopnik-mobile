# Игровой тест v2 — «Гопник: Казань 1998»

**Открыть игру:** https://lenar369.github.io/gopnik-mobile/preview-v2/

По просьбе пользователя вместо длинных текстовых экранов сделан новый оригинальный визуальный интерфейс в духе изометрических survival-RPG. **Не используется графика Day R Survival**. Фон Пятого квартала — оригинальная сгенерированная иллюстрация, встроенная прямо в HTML. Игровая версия работает без внешнего хостинга картинок.

## Тестируемые функции

- Вид квартала сверху под углом: 9 интерактивных точек на карте, нажимать на круглые маркеры.
- Двигать карту: палец/мышь; кнопки + и − для масштаба.
- Нажатие на локацию открывает компактную панель с реальными игровыми действиями; по стрелкам можно переключать следующие действия.
- Четыре начальных варианта героя с разными характеристиками и домашними условиями.
- Дом, сон, отдых, записка Дамира, слухи, дом №12 и накладная №17, выбор финала главы.
- Сумка Зои, свет в подъезде, торговля в киоске, подработка, рюкзак, экипировка, бой/мирное решение.
- Меню: Карта, Вещи, Герой, Задания, Журнал.
- Локальное автосохранение в браузере `gopnik-kazan-dayr-inspired-test-v1`.

## Ограничения

- **Это тест нового интерфейса и прототип первой главы, не вся игра.** Остальные районы пока перечислены, полноценные карты и истории не готовы.
- Иллюстрация содержит в самой картинке некоторые названия зданий, поверх них наложены активные маркеры.
- Полная система экипировки, все 14 глав, глубокая сюжетная репутация и групповые бои пока не реализованы.
- Редактируемые исходники пока находятся в одном HTML со встроенной графикой; перед масштабированием проекта желательно вынести данные, иллюстрации и скрипты отдельно.
- Никаких файлов старой версии `kazan/index.html` или предыдущего `preview-v1` не меняли. Тест имеет независимый ключ сохранения.

## Проверка

- Локальная проверка Playwright Chromium: 320×568, 390×844, 430×932, 1280×720; страница не прокручивается вертикально, 9 маркеров доступны, карточка дома открывается.
- Прохождение через DOM и события UI за все четыре типа героя: получение трёх улик, завершение главы, инвентарь, бой и побег; без ошибок страницы.
- GitHub Pages публикация проверена по HTTP 200, изображение встроено и маркеры присутствуют.
