# Гопник: Казань 1998 — глава 1, тест v3

**Играть:** https://lenar369.github.io/gopnik-mobile/preview-v3/

**Дата:** 16 ноября 2026. Это отдельная сборка, не заменяет существующие `/kazan/`, `/preview-v1/` и `/preview-v2/`.

## По отзывам тестирования

1. Убраны исчезающие уведомления, которые перекрывали игровые действия. События пишутся в журнал, краткие сообщения выводятся отдельно вверху карты и не перехватывают нажатия.
2. Заменена карта Пятого квартала на новую оригинальную иллюстрацию: жилые дома, двор, спортплощадка, дальний двор, гаражи, киоск, остановка. Нет фальшивых заводов и рынков на карте первой главы. Девятый узел (подвал) доступен через дом №12 после поручения Валеры.
3. Расширена сюжетная последовательность: после слуха, записки и накладной нужно проверить независимые свидетельства, восстановить хронологию, поговорить с водителем, исследовать квартиру Дамира, сопоставить документы, решить, кому доверять и где сохранить улику. Добавлена побочная история с кассой Бориса; прежние истории Зои и Валеры сохранены.
4. Одноразовые действия и разговоры исчезают после завершения. Подсказка о следующей цели постоянно видна сверху, нужный объект подсвечен. Другие действия доступны страницами до четырёх кнопок.

## Ограничения

- Продолжительность **30–45 минут пока не подтверждена**. Ранее пользователь прошёл версию за 5 минут; v3 добавляет содержательные эпизоды и повторное расследование, но потребуется фактическое тестирование темпа человеком и дальнейшее развитие главы, чтобы добиться цели без искусственного растягивания.
- Только первая глава; нет полной истории на 14 глав. Другие районы пока не нарисованы.
- Автосохранение **только локальное в браузере**. Ключ `gopnik-kazan-1998-chapter1-v3` не меняет старые тестовые или рабочие сохранения. Переход на v3 начинается заново; прежний прогресс остаётся в своей версии.
- Задание Бориса — дополнительное, не требуется для финала. Сторонние изображения из Day R не используются.
- Иллюстрация — авторская, оригинальная, без копирования графики Day R.
- Внутриигровое ожидание — добровольное, без автоматического восстановления HP. Движение времени только при действиях.
- На мобильных устройствах карта перемещается пальцем, страница не прокручивается.

## Проверено автоматически

- Полные ветки первой главы за 4 типа героя, получение 3 улик, две независимые проверки, хронология, встреча с водителем, проверка квартиры Дамира, доверие, сохранение улик и завершение.
- 3 местных задания: Зоя, Валера, Борис.
- Переключение вкладок, страницы действий, шкаф, экипировка, покупки, ожидание, бой и мирное решение.
- Экраны 320×568, 375×667, 390×844, 430×932: кнопки нижней панели и окно взаимодействия в пределах высоты экрана; отсутствует вертикальная прокрутка страницы.
- Не проведено полное ручное прохождение на реальном iPhone/Android; длина прохождения ещё не измерена.
