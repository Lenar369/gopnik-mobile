# Данные игры (preview-v6/data)

Здесь лежат таблицы игры — их можно править без копания в огромном `index.html`. Файлы подключаются в `index.html` тегами `<script src="data/…">` до основного скрипта.

| Файл | Что внутри |
|---|---|
| `items.js` | `MAT` — хабар (name, icon, `w` — вес кг, `p` — сколько платит скупщик); `SUP` — еда/питьё/лекарства (`cost` — цена, `fx` — эффект: food, warmth, energy, nerves, hp); `goods` — вещи (`slot` — куда надевается, `cost`, `stat` — подпись) |
| `recipes.js` | `RECIPES` — крафт: `need` {id: штук}, `min` — минут, `st` — `any`/`home`, `tool`, `out` |
| `loot.js` | `LOOT` — места обыска: `at` — id места, `t` — {id: вес, чем больше — тем чаще}; `WILD` — места на карте города |
| `shops.js` | `SURV_SHOPS` — что где продаётся (id из `SUP`); `SURV_MEALS` — горячая еда |
| `places.js` | `places` — Пятый квартал; `DISTRICTS` — районы 1–6, места `SP(id, имя, значок, x, y, описание, роль, человек)` |
| `enemies.js` | `ENEMY` — противники: hp, урон, меткость, откуп, опыт, добыча |
| `music.js` | `MUSIC` — список треков {title, src}; mp3 класть в `art/music/` |
| `quests.js` | `CQUESTS` — задания районов (`reward` — ₽) |

## Правила
- Это базовые значения. Часть предметов и мест добавляется позже модулями внутри `index.html` (`Object.assign(goods,{…})` — фонари, кастет, новые гостиницы и т.п.) — они в этих файлах не видны.
- Цены здесь — **до дефолта**; после 17.08.1998 игра сама умножает (еда ×2, заведения ×1,6, скупщик ×1,5).
- id не переименовывать — на них ссылаются сохранения игроков и код.
- После правки — тесты: `cd tests && node run.js` (тесты сами собирают игру с этими файлами).
- Картинка предмета подхватывается сама по имени: `art/items/<id>.webp` (для `MAT` — `mat_<id>.webp`).
