# Автотесты игры

Проверяют `preview-v6/index.html` в jsdom (браузер без окна): синтаксис скрипта и 15 сценариев — меню и новая игра, сцены, ходьба по карте, обыск и крафт, места на карте, прокачка и уровни врагов, драки (разборка и бой на клетках, броски), разговоры, заведения, серьёзные дела, милиция и участковый. Тест пройден, если в игре не было ни одной ошибки JavaScript.

```bash
cd tests
npm install        # один раз — ставит jsdom
node run.js        # проверить preview-v6
```

Другой файл: `node run.js ../preview-v7/index.html`.

**Правило:** перед каждой отправкой изменений игры в GitHub — `node run.js`, и только если «Все сценарии прошли».
